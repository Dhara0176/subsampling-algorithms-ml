# Datasets

The datasets used in this project are publicly available on Kaggle.

## Adult Income Dataset
https://www.kaggle.com/datasets/wenruliu/adult-income-dataset

## Law School Admission Bar Passage Dataset
https://www.kaggle.com/datasets/danofer/law-school-admissions-bar-passage

Download the datasets and place them in the `data/` folder before running the project.
